# Mission: 从数学原理贯通生成模型

## Why
建立一套能够真正用于研究理解的生成模型知识体系：不止会调用模型，而是能从数学、代码和实验现象解释 VAE、Diffusion、DDPM、DDIM、模型变体与 Flow Matching 的内在联系。

## Success looks like
- 能从直觉、概率模型、核心公式和代码四个层次解释每类模型
- 能独立推导并数值验证 KL、ELBO、DDPM 与 Flow Matching 的关键公式
- 能实现最小模型、设计消融实验，并根据训练现象诊断问题
- 能用“分布建模—分布恢复—分布运输”统一比较整条生成模型路线

## Constraints
- 默认读者只有高中代数、函数、基础概率和导数直觉
- 数学按章节即时引入，不预先堆积整门概率论、信息论或微分方程
- 优先使用本地、轻量、可复现的交互实验
- 教材使用中文，保留通用英文术语和数学符号

## Out of scope
- 追求论文级图像质量或大规模训练
- 在理解基础概念之前追逐最新模型名称
- 把现成 pipeline 的调用误认为掌握模型原理
