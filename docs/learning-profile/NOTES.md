# 教学偏好

- 讲解应深入浅出，默认高中数学基础。
- 重要概念先讲生活直觉和具体数字，再讲图形，最后给正式定义。
- 直觉解释与严格证明必须分开，不能相互替代。
- 关键概念允许从不同角度反复解释，但必须保持符号和逻辑一致。
- 可视化优先采用可控制的 slider、逐步轨迹和同屏对照。
- 代码必须详细注释，并明确对应公式、shape、广播和求和维度。
- 专业术语采用中文先行、英文对照；第一次出现时解释中文译名和英文原词，
  后续正文优先中文，代码变量、通用缩写和论文标题保留英文。
- 每章包含理解题、手算题、代码题、探索题及折叠答案。
- 统一教学协议只作为后台验收清单，不应直接表现为每章相同的编号模板；
  章节应根据内容采用探索课、推导课、代码实验、失败诊断或模型比较等不同节奏。
- 交互不只是展示滑块和图，而应形成“先预测—动手实验—即时反馈—解释偏差—迁移应用”的学习循环。
- 教材应像陪伴式学习资料：有问题情境、停顿提示、阶段性成果和选择性深入区，
  避免连续堆叠定义、公式、代码和固定格式练习。
- 昂贵计算必须由按钮显式触发；数学章节默认离线运行。
- 每个课程部分结束后加入经典论文导读；导读应以原文为准，包含教学性中文意译、
  关键公式逐步推导、图形重绘与图注解释、代码逐行映射、数值核验、实验局限和检索练习，
  并且不占用 1–30 章的正式编号。
- 论文数量不能只够支撑一篇孤立导读；应形成可追溯的论文谱系。正式章节给出定点阅读坐标，
  部分末再用专题研讨比较代表论文，且必须说明哪些资料只是拓展阅读、为何不进入当前主线。
- 论文导读不能全部用课程重绘代替原始证据；应适度引用不超过定位需要的原文短句和原图节选，
  紧接教学性中文解释与完整来源。每一张原图或教学图都必须说明颜色、线型、坐标、模块等图例，
  明确“这张图要观察什么”和“它不能证明什么”，避免把可视化当作装饰或数学证明。
