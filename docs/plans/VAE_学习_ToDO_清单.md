## 第二阶段：公式先学“意义”，再学“推导”

### 3. 理解最核心的三条公式
先不要推导，只理解含义。

- [ ] 理解近似后验：`q_\phi(z|x)=N(\mu(x), \sigma^2(x))`
- [ ] 理解重参数化：`z=\mu+\sigma\odot\epsilon, \epsilon\sim N(0,I)`
- [ ] 理解 ELBO 形式：`L = E_{q_\phi(z|x)}[\log p_\theta(x|z)] - D_{KL}(q_\phi(z|x)||p(z))`

对每条公式分别完成：
- [ ] 解释每个符号代表什么
- [ ] 解释这条公式在模型里起什么作用
- [ ] 解释如果没有这条公式或这个设计，会出什么问题

**完成标准**

- [ ] 我不是只会背公式，而是能说出“它为什么存在”

### 4. 只掌握 ELBO 的逻辑拆分，不要求完整推导
- [ ] 理解为什么训练目标由“重构项 + KL 项”组成
- [ ] 理解重构项鼓励什么
- [ ] 理解 KL 项约束什么
- [ ] 理解为什么 KL 太强会伤害重构
- [ ] 理解为什么 KL 太弱 latent space 会失控
- [ ] 写出一句自己的总结：“重构项负责____，KL 项负责____。”

**完成标准**

- [ ] 我能把 ELBO 理解成两个目标的平衡，而不是一条死公式

### 5. 单独吃透 reparameterization trick
这是优先级很高的一步。

- [ ] 理解为什么“直接采样”会阻断反向传播
- [ ] 理解为什么把随机性转移到 `epsilon` 上就可以训练
- [ ] 理解为什么代码里常写 `std = exp(0.5 * logvar)`
- [ ] 自己手写一遍从 `logvar` 到 `std` 到 `z` 的计算过程

**完成标准**

- [ ] 我能不查资料解释“为什么 VAE 可以边采样边训练”
