# 生成模型术语使用规范

本课程采用“中文先行、英文对照”的规则：

1. 专业术语第一次出现时写成“通用中文名（English term，常用缩写）”。
2. 完成首次解释后，正文优先使用中文；公式、代码变量和论文标题保留英文。
3. 缩写必须先展开一次，例如“证据下界（evidence lower bound，ELBO）”。
4. 没有稳定中文译名时直接保留英文，并说明概念，不强行创造中文词。
5. 同一个英文术语只采用一种主译名；其他常见译法只在首次出现时提示。

课程的权威术语数据保存在 `src/teaching/terminology.py`，课程首页会据此生成
完整中英对照表，每章开头也会自动展示该章首次引入的术语。修改译名时应只
修改这个事实源，并运行课程测试，避免不同章节逐渐产生不同译法。

## 容易混淆的译名

| 本课程主译名 | 英文 | 使用说明 |
|---|---|---|
| 潜变量 | latent variable | `latent` 单独出现时，要根据语境译为潜变量、潜在表示或潜空间。 |
| 似然 | likelihood | 它是固定参数或原因后观察数据的函数，不等同于普通口语中的“概率”。 |
| 模型证据 / 边缘似然 | evidence / marginal likelihood | 在本课程的贝叶斯公式中二者指向同一个 (p(x))。 |
| 得分函数 | score function | 指 \(\nabla_x\log p(x)\)，不是评价模型好坏的“分数”。 |
| 归约 | reduction | 指对张量某些轴求和或平均，不是降维模型。 |
| 广播 | broadcasting | 指张量逐元素运算的形状扩展规则，不是消息传播。 |
| 无分类器引导 | classifier-free guidance | “无分类器”表示不需要额外分类器，不表示没有条件信息。 |
| 概率流常微分方程 | probability flow ODE | 这里的“流”是分布随时间的确定性运输。 |
| 耦合 | coupling | 指保持两个边缘分布的联合配对分布，不是普通的模型模块连接。 |
| Rectified Flow | Rectified Flow | 中文译名尚未完全统一，课程保留英文并直接解释其作用。 |
